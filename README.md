# Клейви Чат (Kleivy)

Облачный мессенджер на Supabase. Регистрация, личные чаты, публичные и
частные каналы, отправка изображений и любых файлов, в реальном времени.

## Live
Проект публикуется на GitHub Pages из ветки `main`:
https://limonnyrai.github.io/Kleivy/

## Как это работает
- **Авторизация** — Supabase Auth (email + пароль).
- **Данные (чат, контакты, каналы, сообщения)** — хранятся в облаке
  Supabase (Postgres). Это не localStorage, поэтому все видят общие
  сообщения, а не «только твой профиль на твоём компьютере».
- **Файлы и картинки** — загружаются в Supabase Storage
  (`chat-media`, `avatars`, `channel-avatars`).
- **Live-обновление** — Supabase Realtime (INSERT-подписки).

## Файлы
| Файл | Что делает |
|------|------------|
| `index.html` | Основное приложение (чат, каналы, профиль) |
| `login.html` | Вход в аккаунт |
| `register.html` | Регистрация |
| `script.js` | (демо-скрипт, зарезервировано) |
| `style.css` | Стили для страниц входа/регистрации |
| `supabase-setup.sql` | Миграция для настройки облака |

## Настройка облака (важно!)
Без шага ниже загрузка файлов/картинок и медиа в каналах работать не
будет. Открой **Supabase Dashboard → SQL Editor → New query**, вставь
содержимое `supabase-setup.sql` и нажми **Run**.

Это создаст:
1. недостающие колонки медиа в таблице `channel_messages`;
2. публичные Storage-бакеты `chat-media`, `avatars`, `channel-avatars`;
3. политики загрузки/чтения файлов;
4. автосоздание профиля после регистрации (триггер).

> Ключи подключения (`SUPABASE_URL` / `SUPABASE_KEY`) уже прописаны в
> `index.html`, `login.html`, `register.html`.

## Что исправлено в этом релизе
- Каналы: сообщения больше не отображаются все «от тебя» — теперь
  показывается имя автора и правильное выравнивание.
- Каналы: поддержана отправка и отображение изображений/файлов
  (ранее был запрет «добавлено позже»).
- Любые типы файлов можно прикреплять и отправлять.
- Убрана дублирующаяся логика в конце регистрации.

# Клейви Чат (Kleivy)

## Live
Проект публикуется на GitHub Pages из ветки `main`:
https://limonnyrai.github.io/Kleivy/

## Файлы
| Файл | Что делает |
|------|------------|
| `index.html` | Основное приложение (чат, каналы, профиль) |
| `login.html` | Вход в аккаунт |
| `register.html` | Регистрация |
| `script.js` | (демо-скрипт, зарезервировано) |
| `style.css` | Стили для страниц входа/регистрации |
| `supabase-setup.sql` | Миграция для настройки облака |

## Что исправлено в этом релизе
- Каналы: сообщения больше не отображаются все «от тебя» — теперь
  показывается имя автора и правильное выравнивание.
- Каналы: поддержана отправка и отображение изображений/файлов
  (ранее был запрет «добавлено позже»).
- Любые типы файлов можно прикреплять и отправлять.
- Убрана дублирующаяся логика в конце регистрации.
